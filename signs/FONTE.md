# Sinais de segurança (ISO 7010)

Desenhos vetoriais dos sinais ISO 7010 publicados no Wikimedia Commons (categoria «ISO 7010 safety signs»),
como domínio público ou CC0 pelos seus autores. Obtidos através do pacote npm `@iso-safety-signs/core` 1.1.0
(código MIT, os SVG são os do Commons, sem alterações). O nome de cada ficheiro é o código do sinal na norma.

Usados no acolhimento (o Hardy mostra o sinal de que fala). A norma ISO 7010 é paga; os desenhos não.
